## Why

Decisions (user, 11 Nov; full table and rejected alternatives in the plan, summary in the
ROADMAP Decision Log):

| Topic | Chosen | Rejected, and why |
|---|---|---|
| Weights | one network shared by all intersections | per-intersection nets (cannot run on Hangzhou, 12× parameters); id embedding (not transferable) |
| Ensemble | shared encoder + K independent MLP heads | K full networks (K× compute); K linear heads (correlated, small σ) |
| Attention | one GAT layer, one attention head | multi-head (blurred explanations); two layers (whole-graph replay) |
| σ | std over heads of Q at the greedy action | vote disagreement (only K + 1 levels) |
| τ | p-th percentile of σ on clean val; p chosen on clean + perturbed val; one p, τ per seed-model | clean val only (would select "never fire"); fixed p (arbitrary); safety-constrained (new constant); one global τ (σ scale differs per model) |
| Gate in training | evaluation only | active in training (−gate would need its own runs; gate and weights entangled) |
| Exploration | ε-greedy on mean Q | head sampling (two changes at once vs. the baselines) |
| Head diversity | Bernoulli(0.8) masks + independent init | randomized priors (extra component); init only (σ may collapse) |
| Training search | full grid K {3, 5, 10} × d {32, 64, 128}, seed 0 | wider random search (sparse on K, d); 4-run grid (weak evidence) |
| Ablations | −attention, −ensemble trained on 5 seeds now; −gate from the same checkpoints | smoke runs only / seed 0 only (no ablation numbers before Phase 7) |
| If no gain over DQN | lock the best grid config, no extra tuning | pre-declared second stage (more tuning than the baselines) |
| Math write-up | `docs/methodology.md` | writing directly in `report/` (template not set up) |
| Extra | σ validity check | SHAP, vote logging, animation hook (not selected now) |
| Platform | long runs on native Ubuntu if 0.1b is done, else WSL dev | — |

## Execution log (12 Nov, native Ubuntu)
- Step 1: protocol §9 clarification row (gate at evaluation only, τ rule, ablation
  definitions); PRD §9 τ question closed.
- Step 2: replay `extras` columns, bootstrap masks (stream seed + 40 000), masked ensemble
  loss, `sigma_mean`, shared-agent `load` checks phase set / state shape instead of the
  intersection list. DQN regression: 2 CityFlow training episodes before / after the change
  → same loss, same weight hash. Found and fixed: training rows were always labelled
  `dev-WSL` (also the 10 native rows of worklog/018 — left as is, append-only log).
- Step 3: `NeighborhoodEncoder` (5 × 45 per intersection) and `UGMARLNet` (embedding + slot
  embedding, 1-head GAT layer over self + 4 neighbours, K stacked MLP heads; parameter-count
  formula `expected_params`; d = 64, K = 5 → 103 400 parameters). 8 tests.
- Step 4: `UGMARLAgent` (μ, σ, gate with internal Max-Pressure, explanations, ablation flags,
  architecture-checked checkpoints), `gate.py` (σ, percentile τ, p selection, `gate.json`),
  registry `ugmarl`, `model_label`, `agents.ugmarl` block in `base.yaml`, configs `ugmarl`,
  `ugmarl_noattn`, `ugmarl_noens`, `eval_ugmarl`. Tests: τ = −1 reproduces Max-Pressure's
  actions over a whole episode, τ = ∞ equals gate off, strict σ > τ, no gate while exploring.
  196 passed.
- Step 5: `eval/explain.py` `DecisionRecorder`; `run_episode(recorder=)`; `evaluate`
  resolves τ per seed (`gate.tau` or `gate.json`, refuses a gated run without τ before
  writing anything), logs the variant name, τ and its source; `evaluate.py --log-decisions`.
  202 passed.
- Step 6 (smoke, CityFlow, Jinan): 2-episode runs of full / −attention / −ensemble write
  every training output; experiment-log model names `ugmarl`, `ugmarl-noattn`,
  `ugmarl-noens`, note `native`. Val evaluation of the full smoke model: **τ = 0 →
  326.1141 s, fallback 1.00 = Max-Pressure exactly**; τ = 10⁹ and `use_gate=false` →
  both 1373.46 s, fallback 0 (= the training-time val score); no τ → refused (exit 2).
  Same seed twice → same weight hash. CUDA unavailable on native → no device benchmark,
  CPU kept.
- Step 7 (sanity, seed 0, K = 5, d = 64, 100 episodes, alone on the machine, 9.5 min):
  best val **306.6 s** (episode 95; FT 434.8, MP 326.1, DQN seeds 298.9–301.6); training
  σ (`sigma_mean`) 0.044 → 0.005 (≈ 2 % of |Q|) — small but not collapsed. Timing: K = 10,
  d = 128 ≈ 9.5 s / training episode vs ≈ 5.5 s for K = 5, d = 64.
- Step 8: native platform confirmed; search files committed before any trial.
- Step 9 (grid, seed 0, 5 workers, ≈ 40 min, every run exit 0) — best val travel time (s):

  | K \ d | 32 | 64 | 128 |
  |---|---|---|---|
  | 3 | 305.05 | 306.56 | **301.90** |
  | 5 | 307.36 | 306.61 | 302.83 |
  | 10 | 308.91 | 301.52 | 301.08 |

  Rule: best 301.08 (K 10, d 128); within 1 s: 301.52 (K 10, d 64), 301.90 (K 3, d 128) →
  smallest K → **K = 3, d = 128 locked** (`configs/ugmarl.yaml`). d = 128 is best for every
  K; K has no clear effect. The K = 5, d = 64 trial reproduces the sanity run exactly
  (306.6119 s). Caveat for the report: σ over 3 heads is a noisy estimate. Run time 12–18 min
  per run with 5 in parallel.
- Step 10 (finals, full model, seeds 0–4, 5 in parallel, ≈ 18 min each): best val
  301.90 / 303.04 / 301.97 / 301.18 / 300.95 s (seed 0 = grid t2 exactly).
- Step 11a (gate calibration, full model; 125 val episodes, ≈ 6 min with 4 workers while
  the −attention finals trained): scores p 80 / 90 / 95 / 99 = 343.73 / 343.69 / 346.56 /
  347.76 s → 80 and 90 tie within 1 s → **p\* = 80** (τ = 0.0055–0.0071 per seed); ungated
  reference 485.24 s. Clean: gated 302.3 vs ungated 301.8 s, fallback 0.211 (≈ 1 − 0.8 ✓).
  **Noise 0.1 / 0.2: ungated collapses to 599.2 ± 54.9 / 908.8 ± 48.3 s; gated 376.5 ± 4.2 /
  423.4 ± 7.5 s, fallback 0.81 / 0.96, max wait 990 / 1238 s vs 2185 / 3307 s ungated.**
  Dropout 10 / 20 %: gate ≈ no gate (306.0 vs 306.1, 310.6 vs 310.3 s).
- σ check (full): median σ / clean median = 4.18 (noise 0.1), 10.82 (noise 0.2), 1.02 /
  1.06 (dropout 10 / 20 %); **Spearman ρ(σ, |TD error|) on clean val = 0.03 ± 0.03**
  (per seed −0.02 … 0.06), top / bottom σ decile |TD| ratio 1.10. Reading: σ flags corrupted
  inputs (out-of-distribution), but does not rank in-distribution value errors. First
  figure had overlapping tick labels; re-run with the fix repeated the 5 TD episodes, so
  `sigma_check_ugmarl_final_s0–4` appear twice in the experiment log (identical values);
  the script now caches `td.csv` and re-plots without simulating.
