# 017 — Phase 6: proposed UG-MARL (attention, Q-ensemble, uncertainty gate)
**Date:** 2026-11-11   **Tag:** decision, code, experiment   **ROADMAP:** 6.1–6.7   **Status:** in-progress

## What
Planning only so far: the design of UG-MARL was decided with the user (15 decisions) and
written as an implementation plan, `.claude/plans/phase6-ugmarl.md`. No code has been written
and no run has been made. Execution continues in this entry.

## Why
ROADMAP Phase 6 (F4, F7, F10; R4, R5; G8). The plan fixes every methodological choice before
any UG-MARL training, as the guidelines require, and is written so that another session on
native Ubuntu can execute it (section "Handoff").

Decisions (user, 11 Nov; full table and rejected alternatives in the plan, summary in the
ROADMAP Decision Log):

| Topic | Chosen | Rejected, and why |
|---|---|---|
| Weights | one network shared by all intersections | per-intersection nets (cannot run on Hangzhou, 12× parameters); id embedding (not transferable) |
| Ensemble | shared encoder + K independent MLP heads | K full networks (K× compute); K linear heads (correlated, small σ) |
| Attention | one GAT layer, one attention head | multi-head (blurred explanations); two layers (whole-graph replay) |
| σ | std over heads of Q at the greedy action | vote disagreement (only K + 1 levels) |
| τ | p-th percentile of σ on clean val; p chosen on clean + perturbed val; one p, τ per seed-model | clean val only (would select "never fire"); fixed p (arbitrary); safety-constrained (new constant); one global τ (σ scale differs per model) |
| Gate in training | evaluation only | active in training (−gate would need its own runs; gate and weights entangled) |
| Exploration | ε-greedy on mean Q | head sampling (two changes at once vs. the baselines) |
| Head diversity | Bernoulli(0.8) masks + independent init | randomized priors (extra component); init only (σ may collapse) |
| Training search | full grid K {3, 5, 10} × d {32, 64, 128}, seed 0 | wider random search (sparse on K, d); 4-run grid (weak evidence) |
| Ablations | −attention, −ensemble trained on 5 seeds now; −gate from the same checkpoints | smoke runs only / seed 0 only (no ablation numbers before Phase 7) |
| If no gain over DQN | lock the best grid config, no extra tuning | pre-declared second stage (more tuning than the baselines) |
| Math write-up | `docs/methodology.md` | writing directly in `report/` (template not set up) |
| Extra | σ validity check | SHAP, vote logging, animation hook (not selected now) |
| Platform | long runs on native Ubuntu if 0.1b is done, else WSL dev | — |

## Result
Plan ready, not executed. Points to watch during execution:
- τ = 0 must reproduce Max-Pressure's validation travel time (326.11 s) exactly — the main
  correctness check of the gate.
- DQN is already strong on validation (299.8 s, WSL dev), so UG-MARL may not beat it on clean
  flows; that outcome is locked and reported, not tuned away.
