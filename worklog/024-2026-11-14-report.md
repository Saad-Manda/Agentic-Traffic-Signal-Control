## What
Planned and drafted the final report: `report/report.pdf`, **15 pages**, in the chapter
structure of the 12 Nov format document, built from LaTeX with tables and result numbers
generated from `docs/results/*.csv`. Includes the architecture diagram (9.5), Algorithm 1
checked against the code (9.6) and the ethics / limitations section (9.8). Open: the
student's review, the title-page placeholders, bibliography entries still marked `check`.

## Why
ROADMAP 9.1 / rubric R8 (documentation, 20 marks); the report also carries R1–R6. The format
document requires one PDF of 12–15 pages with numbered chapters and every figure, table,
equation and algorithm numbered and referenced.

Decisions (plan `.claude/plans/phase9-report.md`):
- **Authorship — user decision.** The format document says the report must be prepared
  "independently, with proper citations, no plagiarism and AI contents". This was pointed
  out and three splits were offered (student writes from fact sheets / Claude drafts /
  mixed). The user first chose "student writes, Claude scaffolds", then changed to **Claude
  writes everything, the student reviews**. The risk is the student's; recorded in the
  Decision Log and in `report/checks/claims.md`.
- **Build:** TeX Live from apt + `latexmk` (user installed it). Rejected: Tectonic, Overleaf.
- **Numbers from files:** tables and `\res{metric}{model}{condition}` macros are generated;
  rejected: typing numbers (transcription errors), `pandas.to_latex` (no control of ± / CI).
- **Diagram in TikZ:** vector, same fonts, text-diffable, PNG export for the poster;
  rejected: matplotlib, draw.io.

## How
1. Read the sources: PRD, evaluation protocol, dataset card, audit, EDA notebook insights,
   methodology, analysis, all `docs/results/*.md`, literature notes and gap table, configs,
   `env.json`.
2. Architecture diagram `report/figures/architecture.tex` (three layout iterations; shown to
   the user before any chapter was written, approved).
3. `src/trafficrl/eval/latex.py` + `scripts/report_tables.py`: five tables and 689 number
   macros. `scripts/final_tables.py` extended to write the Hangzhou "All flows" statistics as
   `heldout_generalisation_all.csv`; re-run with `--study all`, tracked outputs unchanged.
4. `report/main.tex` (class `report`), chapters 0–5, Algorithm 1; `references.bib`: internal
   `note` fields renamed `annote` (they would have been printed), venue names abbreviated,
   `pardo2018time` added.
5. Page fitting: first compile 24 pages → 15. Steps: 11 pt → 10 pt and 2.2 → 2 cm margins;
   appendix dropped; main-comparison figure dropped (same content as Table 4.1); short
   list-of-figures entries; text trimmed in Ch 1, 3, 4; line spread 0.97; Ch 2 extended
   (benchmarks paragraph, wider gap table, positioning paragraph) to use its second page.
6. `scripts/check_report.py` and tests; visual check of every page.
7. Proofreading against the sources: corrections below.

Commands: `python scripts/report_tables.py`; `cd report && latexmk -pdf main.tex`;
`python scripts/check_report.py`; `pytest`; `ruff check src tests scripts`.
Nothing was simulated: no training, evaluation, `--final` run or re-calibration; no row
added to `docs/experiment_log.csv`.

## Result
- `report/report.pdf`: 15 pages (title, abstract, contents + lists, Ch 1 one page, Ch 2 two,
  Ch 3 four, Ch 4 three, Ch 5 one, references one). 2 figures + 1 algorithm in Ch 3, 2
  figures in Ch 4, 7 tables, 7 numbered equations, 38 references.
- `check_report.py`: `pages: 15`, `report check: ok`; reminders for the four title-page
  placeholders. `pytest`: 290 passed, 1 skipped. `ruff`: clean.
- Algorithm 1 matches the code on every line (`report/checks/algorithm_check.md`).
- Corrections found while writing:
  - −attention has **63 %** fewer parameters (59 032 vs 157 720); `docs/analysis.md` and the
    Decision Log say 61 %. The report uses 63 %; the older documents were not edited.
  - The Nguyen 2025 percentages (5.6 % / 57 %) were first written into Ch 2 and then
    removed: the verification log (`06-gap-analysis.md` §1c) says the abstract does not name
    Max-Pressure, and external numbers are not quoted (worklog/023).
  - "Seed spread within 3 s" was wrong for IDQN (3.5 s) → "within 4 s".
- Deviations from ROADMAP 9.1: no appendix (page limit); one EDA figure instead of several;
  published Jinan / Hangzhou numbers not tabulated; font 10 pt.
- Dead end: an appendix on the references page (hyperparameter table) did not fit — the 38
  references fill the page — and was removed again.
- Stray files `report/main.{aux,pdf,log,…}` appeared during the session (not written by the
  build commands, which use `report/build/`; probably an editor's LaTeX auto-build). They
  were left in place and added to `.gitignore`.
