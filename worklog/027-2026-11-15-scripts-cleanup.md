# 027 — Repo cleanup, step 1: remove scripts not needed for the model (2026-11-15)

## What
Removed 7 of the 19 scripts in `scripts/`, the library modules and tests that only they used,
and the report/poster check files. Fixed every reference to them in code, docs, README and
CLAUDE.md. Before starting, the full repo was saved on branch `archive/full-dev` (`d6cd3b9`).

## Why
This is the first step of the repo cleanup: keep only what trains, evaluates and explains the
model, plus the scripts that produce a number cited in the report. Rule (user decision 15 Nov):
a script stays if the report or poster cites its result. That rule also kept `sigma_check.py`
(report §4: Spearman ρ ≈ 0.03 between σ and TD error) and `lock_models.py` + `eval/lock.py`
(report §3: "the manifest had locked the models"), which the first plan had marked for
removal. `val_table.py` and `final_tables.py` stay as two separate files (user decision).

## How
- Kept (12): `train`, `tune`, `evaluate`, `calibrate_gate`, `robustness`, `lock_models`,
  `val_table`, `final_tables`, `plot_training`, `sigma_check`, `tau_sweep`,
  `attention_faithfulness`.
- Removed (7): `bench_cityflow`, `dataset_stats` (setup / one-off), `audit_data`,
  `collect_traces` (Phase 3, outputs already saved), `report_tables`, `check_report`,
  `build_poster` (report / poster tooling; their outputs are now plain static files).
- `trafficrl.data.{audit,trace,eda}` stay because the EDA notebook imports them.

## Result
- `ruff check src tests scripts`: all checks passed. `pytest`: 275 passed, 1 skipped.
- `python scripts/final_tables.py --study all` reproduces every `docs/results/*` file
  byte for byte; `latexmk -pdf main.tex` still builds the report at 12 pages.
- The EDA notebook can no longer be re-executed from scratch (its trace collector is gone);
  its outputs are saved in the notebook.
