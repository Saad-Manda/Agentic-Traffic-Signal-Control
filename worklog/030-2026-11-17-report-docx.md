# 030 — Word (.docx) version of the report

**Date:** 2026-11-17 · **Phase:** 9.1 · **Type:** report

## What
Made `report/report.docx`, an editable Word version of `report/report.pdf` with the same text,
numbers, tables, figures and references.

## Why
The user asked for a .docx copy of the report.

## How
- Rebuilt the LaTeX into a scratch folder to get `main.aux` (label numbers) and `main.bbl`
  (reference list); the repo's `report/build/` had been cleaned.
- A flattening script (scratchpad, not in the repo) inlined every `\input` and replaced each
  `\res{}{}{}` with its value from `generated/numbers.tex`. It also turned `\cref` into
  "Table 4.1" / "Eq. (3.6)" etc. from the aux file, and `\citep` / `\citet` into IEEE `[n]`
  numbers. It numbered captions and equations, converted the PDF figures to PNG (220 dpi) and
  rendered Algorithm 1 to a PNG with pdflatex (it stays an image in Word).
- pandoc 3.9 (pip `pypandoc_binary`, scratch venv) converted the flat LaTeX to docx, with
  equations as native Word equations, a contents field, and lists of figures and tables.
- python-docx then restyled it: A4, 2 cm margins, Times New Roman 11 pt, black headings,
  booktabs-style tables at 8.5 pt with columns sized so no number wraps, rows that do not split
  across pages, and centred figures. It also sets `updateFields`, so Word fills the contents
  lists when the file is opened.
- Checked a LibreOffice render page by page. A text comparison against the PDF found no
  missing content: every mismatch was table borders, image placeholders or list markers.

## Result
`report/report.docx`, 16 pages in LibreOffice (the PDF is 13 pages; Word's layout differs
from LaTeX and the page limit applies to the PDF). The contents and the lists of figures and
tables stay empty until Word updates the fields. Word asks to do this on opening; answer Yes.

**Overleaf zip (same day).** `report/overleaf.zip`: `report/` made self-contained for
Overleaf's "Upload Project" (the four figures from `docs/figures/` copied into `figures/`,
`\graphicspath{{figures/}}`, no `latexmkrc`); test-compiled with `latexmk -norc`, 13 pages, no
undefined references.

The user then moved `report/report.docx` and `report/overleaf.zip` out of the repo, so neither
file is tracked.
