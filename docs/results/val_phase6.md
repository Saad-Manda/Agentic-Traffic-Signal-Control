# Phase 6 — validation results, UG-MARL and ablations (native Ubuntu)

Jinan `real_2000` (validation flow), 3600 s, Δt = 15 s, clean detectors. Mean ± std [95 % CI, Student t] over seeds 0–4; a learned model's seed s is evaluated with the checkpoint trained with seed s (best ungated validation episode). Rule-based baselines are deterministic. UG-MARL: K = 3, d = 128 (grid study); gate τ = 80th percentile of each model's clean-validation σ (`gate.json`, p* = 80 chosen on clean + noisy / dropout validation, `docs/results/gate_calibration.md`); −gate = the same checkpoints with the gate off; −attention has its own τ (same p); −ensemble has K = 1 and no gate. All rows native Ubuntu (DQN / IDQN re-run natively, worklog/018). Validation was used for checkpoint, (K, d) and p selection, so learned-model scores are optimistic. Training time = wall time of 100 episodes + 20 val episodes on CPU with 5 runs in parallel; decision latency measured on an idle machine. Generated by `scripts/val_table.py`.
