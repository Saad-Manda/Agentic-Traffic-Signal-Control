# Attention faithfulness check — ugmarl (validation)

Generated by `scripts/attention_faithfulness.py --tag final`. Jinan `real_2000` (validation flow), clean detectors, seeds 0, 1, 2, 3, 4 (seed s = model trained with seed s), UG-MARL as deployed (gate on); each episode reproduces the Phase 6 validation travel time. For every decision with at least two neighbours, one input slot is perturbed and the network is run again (attention recomputed): **replacement** = the slot's 44 values are swapped for the same slot's values from another decision of the same intersection in the same episode (mean of 8 draws); **knock-out** = the slot is masked as absent. μ is the ensemble-mean Q in scaled reward units. An association check on validation data, not a causal claim; nothing is fitted or selected.
