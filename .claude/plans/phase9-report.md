## Design

### Layout of `report/`

```
report/
  main.tex               # class, packages, title page, front matter, \include chapters
  latexmkrc              # pdflatex + bibtex, output to report/build/
  chapters/
    00-abstract.tex
    01-introduction.tex  02-literature.tex  03-methodology.tex
    04-results.tex       05-conclusion.tex  A-appendix.tex
  tables/                # generated (*.tex), tracked
  generated/numbers.tex  # generated macros, tracked
  figures/
    architecture.tex     # TikZ standalone (9.5) -> architecture.pdf / .png
    algorithm.tex        # Algorithm 1 (9.6), \input by Ch 3
  checks/                # claims.md, algorithm_check.md  (not compiled)
  references.bib         # exists (65 entries)
  report.pdf             # final PDF, tracked; build/ is gitignored
```

- Class `report`, A4, 11 pt, 2.2 cm margins, `titlesec` for compact chapter heads (each chapter
  still starts on a new page and is numbered). Packages: `graphicx`, `subcaption`, `booktabs`,
  `siunitx`, `amsmath`, `algorithm` + `algpseudocode`, `hyperref`, `cleveref`, `natbib`
  (numeric, `IEEEtranN` style).
- Results figures are included **from where they already are** (`\graphicspath` →
  `docs/figures/results/*.pdf`, `docs/figures/eda/*.png`). No copies.
- Chapter files follow the section order of the format document exactly (section titles as
  given there).
- Title page: `[Author Name]`, `[Roll No.]`, `[E-mail]`, `[Department]` placeholders.

### Architecture diagram (9.5)

Blocks in data-flow order, two lanes:

- **Shared front:** raw flows → split (train / val / test; held-out city) → observation
  (44 values, lane-capacity scaling, *nothing fitted*) → CityFlow environment.
- **Training path:** ε-greedy on mean Q → replay buffer → K-head update with bootstrap masks
  and target network → checkpoint by ungated validation → τ = p\*-th percentile of σ on
  validation (**marked "fitted here"**).
- **Inference path:** own + neighbour observations → attention encoder → K Q-heads → μ, σ →
  gate (σ > τ ? Max-Pressure : argmax μ) → phase → metrics; side outputs: attention weights,
  gate-firing log.


### Algorithm 1 (9.6)

Start from the draft in `.claude/reference/architecture.md`, then check each line against
`train/loop.py`, `agents/core/` (QLearner, replay), `agents/ugmarl/{network,agent,gate}.py`,

`report/checks/algorithm_check.md` (line → file:function → matches? → note). Known points to
verify: grid on seed 0 with the 1 s tolerance / smallest-K rule; p grid {80, 90, 95, 99};
τ per seed-model; gate off during training and checkpoint selection; seeds 0–4.

## Justification

- **Claude writes (R1):** user decision; the content already exists in checked project
  documents, so the work is selection, compression to 12–15 pages and consistent wording.
  The alternative (student writes from fact sheets, Claude checks) was offered and declined.
- **Generated tables and macros (R5):** the report has ~7 tables and several dozen numbers
  that also appear on the poster. Rejected: typing them by hand (error-prone, no check);
  `pandas.to_latex` directly (no control over ± / CI / deterministic formatting).
- **LaTeX `report` class:** the format document requires numbered chapters each starting on
  a new page, lists of figures and tables, and numbered cross-references — all native.
- **Figures reused as they are:** Phase 8 already produced PDF figures with a tested function
  each; redrawing them would create a second, unchecked source.
